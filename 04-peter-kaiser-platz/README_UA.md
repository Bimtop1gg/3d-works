# 3D-модель Ландтагу Ліхтенштейну (Peter-Kaiser-Platz) 

**Статус:** Work in Progress (WIP)  
**ПЗ:** Blender  
**Напрямок:** Architecture 3D Modeling / Environment Design  
**Стиль:** Сучасна архітектура / Мінімалізм  

---

## Опис проекту

Проект із відтворення архітектурного ансамблю площі Петера Кайзера (**Peter-Kaiser-Platz**) у Вадуці — політичного серця Ліхтенштейну. 

Наразі змодельовано головну будівлю сучасного парламенту — **"Високий будинок" (Hohes Haus)**. Проект знаходиться в активній розробці.

---

## План розробки (Roadmap)

- [x] **"Високий будинок" (Hohes Haus):** Моделювання основної будівлі Ландтагу, цегляного фасаду, решіток та вхідної групи.
- [ ] **Друга частина парламенту:** Моделювання сполучної будівлі (Verbindungshaus).
- [ ] **Історичний урядовий будинок:** Відтворення класичної історичної будівлі парламенту/уряду (Regierungsgebäude).
- [ ] **Ансамбль площі:** Повна збірка оточення та ландшафту площі Петера Кайзера (Peter-Kaiser-Platz).

---

## Технічні особливості

* **Цегляна кладка фасаду:** Деталізоване опрацювання текстури та геометрії світлої клінкерної цегли.
* **3D-напис фасаду:** Вручну відтворений об'ємний напис *«LANDTAG DES FÜRSTENTUMS LIECHTENSTEIN»* на стіні біля входу.
* **Архітектурні елементи:** Моделювання перфорованих цегляних решіток (сонцезахисних фасадних елементів), похилого даху та прапора Ліхтенштейну.
