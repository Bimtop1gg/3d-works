# Збірник 3D робіт

У цьому репозиторії зібрано мої проекти у сфері 3D-моделювання: від деталізованих технічних об'єктів (Hard-Surface) до складних архітектурних ансамблів.

---

## Проекти

| Назва проекту | Категорія | Короткий опис | Детальніше |
| :--- | :---: | :--- | :---: |
| **01. FPV Дрон** | Hard-Surface | Модель військового FPV дрона з платою детонатора та снарядом. | [Переглянути](01-fpv-drone/README_UA.md) |
| **02. Неоготична вулиця** | AI -> 3D Pipeline | Адаптація та відтворення 2D AI-концепту в чисту 3D-геометрію. | [Переглянути](02-neogothic-street/README_UA.md) |
| **03. Собор Св. Флоріна** | Architecture | 3D-реконструкція Кафедрального собору Святого Флоріна у Вадуці (Ліхтенштейн). | [Переглянути](03-st-florian-vaduz/README_UA.md) |
| **04. Площа Петера Кайзера** | Arch Ensemble (WIP) | Масштабний архітектурний ансамбль парламенту та уряду Ліхтенштейну. | [Переглянути](04-peter-kaiser-platz/README_UA.md) |

---

## Навички та інструменти

* **Основне ПЗ:** Blender
* **Напрямки:** Hard-Surface моделювання, архітектурні ансамблі, робота з кресленнями та референсами, адаптація AI-концептів.
* **Технічний підхід:** Оптимізована геометрія, чиста топологія (Wireframe), деталізація вузлів.
