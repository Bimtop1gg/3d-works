# 3D-модель Собору Святого Флоріна (Вадуц)

**ПЗ:** Blender  
**Напрямок:** Architecture 3D Modeling / Environment Design  
**Стиль споруди:** Неоготика (Gothic Revival)  

---

## Опис проекту

3D-модель кафедрального собору Святого Флоріна — головної архітектурної пам'ятки Вадуца (Ліхтенштейн), збудованого у 1873 році за проектом архітектора Фрідріха фон Шмідта. 

Проект зосереджений на точній передачі неоготичного стилю, архітектурних пропорцій та деталізації фасадних елементів.

---

## Технічні особливості

* **Архітектурні деталі:** Моделювання вежі-дзвіниці, вежового годинника, стрільчастих вікон, декоративних пінаклів та хреста на шпилі.
* **Фасадні елементи:** Додано геральдичні прапори Ліхтенштейну та кам'яну текстуру фасадів.
* **Оптимізована геометрія:** Чиста топологія сцени з правильною сіткою для архітектурної візуалізації.
